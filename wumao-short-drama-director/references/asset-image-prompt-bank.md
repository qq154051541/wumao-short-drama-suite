## 一、 万能六槽公式（速写档）

```
主体 + 场景 + 风格 + 光影色调 + 构图质感 + 比例用途
例：city walk 女孩 + 街头咖啡馆 + 电影感 + 黄金时刻逆光 + 35mm 浅景深 + 竖版 3:4
```

| 槽 | 填什么 | 与本包上位权威的对应 |
|---|---|---|
| 主体 | 谁 / 什么东西 | 【核心人物】/ 三模板角色锚 |
| 场景 | 在哪、背景几何 | 【场景资产】/ 九宫格 8 字段 |
| **风格** | 电影感 / 水墨 / 胶片 / 扁平插画… | ⚠️ **正式稿必须回 `style-bible/` 取 11 槽位正主词**，本槽只是试片占位 |
| **光影色调** | 逆光 / 伦勃朗布光 / 青蓝藏青 / 暖橙 | 【场景资产】的**时段光影基准**（镜行只写增量） |
| 构图质感 | 35mm 浅景深 / 俯视 45 度 / 胶片颗粒 / 微距 | `camera-specs-15rules.md` 焦段 + `aspect-ratio-adaptation.md` 画幅 |
| 比例用途 | 竖版 3:4 / 16:9 投屏 / 3.35:1 公众号封面 | **B 锁画幅**（成片）；⚠️ 资产板整板画布固定 16:9，不随成片画幅变 |

- **与 style-bible 11 槽位不冲突**：11 槽位是**全片冻结的工业参数**（锁定后每镜都带）；六槽是**单张试片的一句话公式**（不锁定、不继承）。试片确认方向 → 回 `style-lock-ladder.py` 取卡 → 再按 I 锁流程弹卡让用户确认，**顺序不能反**。
- `python3 scripts/expression_motion.py --formula` 可列出全部 11 套公式（10 套动作 + 本套生图）。

## 三、 5 条高密度角色范式 + 10 段描写维度模板

原文 5 条提示词每条 **379~507 字**（完整全文见机读库 `portrait` 族，`--list portrait` 可查），远长于普通速写。它们的价值不在「抄这 5 张图」，而在**共同暴露了一套可复用的描写维度**——这正好补上本包角色四格模板在「怎么把一张脸写透」上的空白。

### 3.1 十段描写维度（从 5 条原文归纳，不是原文小标题）

| # | 维度 | 要写清什么 |
|---|---|---|
| 1 | **机位与透视** | 高角度俯拍 / 低角度仰拍 / 平视；近大远小的透视关系 |
| 2 | **主体位置** | 画面中央偏右 / 偏左；头部朝向；全身或半身 |
| 3 | **五官与视线** | 发型发色、碎发、肤质、表情、眨眼、视线落点 |
| 4 | **服装与材质** | 上下装形制、面料、薄纱 / 针织 / 牛仔、配饰、露肤与滑落 |
| 5 | **光线与光比** | 光源方向（左上方 / 右后方）、硬光或柔光、高光位置、投影长短、光比强弱 |
| 6 | **色彩系统** | 主色 / 辅助色 / 点缀色；冷暖对比；饱和度 |
| 7 | **背景几何** | 虚化城市街道 / 高架桥 / 围网 / 门窗；天空占比 |
| 8 | **空间分层** | 前景（虚化遮挡）→ 中景（人物清晰）→ 背景（虚化） |
| 9 | **情绪定调** | 夏日轻松明亮自信 / 冷峻孤绝危险而克制 / 安静私密古典诗意 |
| 10 | **后期质感** | 胶片颗粒、镜头光晕、磨皮程度、保留皮肤自然质感、无过度锐化 |

## 四·五、 爆款短剧颜值锚点库（P2 写角色提示词前**必查本节**）

> ★ 2026-11-20 实测建库。起因：用户连续反馈「脸展示不全」「沈琳是侧脸」「人物还是很丑」，要求「参考爆火短剧男女主角长相」。本节是对红果/抖音爆款短剧头部演员公开颜值描述的结构化提炼，供角色提示词直接取参。

### 4.5.1 三铁律（治「脸被裁」「侧脸」「丑」）

| # | 铁律 | 病根（我踩过的） | 正确写法 |
|---|---|---|---|
| **1** | **正面锚定三连**：必须同时写「身体正对镜头」「面部朝向正前方」「双眼平视直视镜头」，再加一句「鼻尖与面部中线正对镜头，头不偏不侧」 | 只写五官不写朝向 → 模型自由发挥偏头 → 侧脸/四分之三脸 | 见 4.5.4 可复制模板 |
| **2** | **完整入画 + 四缘留白**：写「整个头部完整入画，从头顶发丝最高点到下巴底缘全部落在格内，头顶留白约半格高、下巴下方留出空隙，脸部四缘都不贴画面边」 | ⛔ 写「**头部填满该格**」→ 模型把头撑到溢出画框 → **脸被裁掉**（知夏踩过） | 用「完整入画 + 留白」，绝不用「填满」 |
| **3** | **正面柔光，禁侧光**：写「正面柔光主光从镜头方向正面打亮，左右光量对称均匀，额头/鼻梁/两颊/下巴受光均匀明亮，脸部两侧没有半边阴影」 | ⛔ 写「**侧光从右侧斜入**」「侧逆光」→ 模型理解为侧光照脸 → **直接画侧脸**（沈琳踩过） | 主光必须正面；轮廓光只勾发丝边缘，不照脸 |

> ⚠️ 这三条与 §四避坑第 1 条同源：**都用正向描述**。不写「不要侧脸」，而是写「面部朝向正前方、直视镜头」——写正面要什么，模型才给什么。

### 4.5.5 出图前自检五问（答不上就重写）

1. 有没有「身体正对镜头 + 面部朝向正前方 + 直视镜头」三连？
2. 有没有「头顶到下巴完整入画 + 留白」，而不是「填满/占满」？
3. 主光是不是**正面**？有没有出现「侧光/侧逆光/斜入」照脸的词？
4. 颜值锚点是不是**只选了一个型**、且骨相/五官/皮肤三段齐全？
5. 有没有「不过度磨皮 / 保留毛孔」？（缺了就是塑料网红脸）

### 4.5.6 「人不够好看 / 太普通」怎么升级（2026-11-20 用户要求）

> ★ 用户原话：「知夏还是不够好看，很普通，**不要完全按照小说的描述**」。
> 由此确立原则：**原著外形描述只作「识别锚点」，不作颜值上限。** 观众看的是脸，不是设定忠实度——原著写「清纯大学生」不等于要画成普通路人。

**四个升级档位**（按"普通 → 出挑"推进，逐条替换原描述）：

| # | 档位 | 从（普通） | 到（出挑） |
|---|---|---|---|
| 1 | **脸型收紧** | 圆润鹅蛋脸 / 带婴儿肥 | **巴掌小脸**、标准鹅蛋脸、脸型**极流畅**、下颌柔和小巧收拢，脸颊有恰到好处的胶原感而**不圆钝** |
| 2 | **五官精度** | 圆眼、小圆鼻头、唇小巧 | **杏眼眼形偏长 + 清晰的双眼皮 + 卧蚕饱满 + 睫毛浓密分明**；鼻梁**小巧挺立有高度**、鼻头微翘；唇**饱满有唇峰**、水润蜜桃色、嘴角上扬 |
| 3 | **妆发质感** | 无妆感、及肩微卷 | **高颅顶 + 及胸微卷大波浪 + 发根蓬松 + 发丝分明有光泽**；**精致淡妆、眼妆干净、腮红自然** |
| 4 | **皮肤光感** | 白里透红 | **冷白透亮、水光通透感、有自然血色** |

**造型同步升级**：⛔ 不要照抄原著的土搭配（如「短款包臀牛仔短裤 + 肉色丝袜 + 白色平底鞋」会直接拉低质感）。做法是**保留 1–2 个识别锚点**（例如「淡紫」+「牛仔」），把版型换成当下审美：`浅紫针织短款上衣 + 高腰浅蓝直筒牛仔裤 + 白色小皮鞋`。

**验证口径（一句话）**：这张脸丢进爆款短剧的男女主里，观众是划走还是记住？记不住就继续往上升档。

## 五、 接线：怎么真正用进 P2 / P2.5

```bash
python3 scripts/expression_motion.py --list image              # 100 条全表
python3 scripts/expression_motion.py --list portrait           # 5 条范式 + 全文长度
python3 scripts/expression_motion.py --query "园林 水墨 场景"   # 跨族检索
```

| 阶段 | 怎么用本库 | ⛔ 别这么用 |
|---|---|---|
| **P2 立项 / 找感觉** | 用六槽公式快速出 1~3 张氛围试片，给主人看方向（**先试片再放量**） | ⛔ 拿试片当资产板交差 |
| **P2 正式资产板** | 从 `image` 表借「布光 / 质感 / 色调」措辞；从 `portrait` 十段维度补角色描写的细节密度 | ⛔ 用短提示词替代三模板逐字段落纸；⛔ 六槽的「风格」占位词冒充 I 锁正主槽位词 |
| **P2.5 出图提示词** | 按 `asset_clause()` 组句，附画幅与用途 | ⛔ 把出图提示词整段粘进 P4【场景资产】或镜行 |
| **P4 投喂** | **本库不参与** | ⛔ 出现「ins 风 / 胶片颗粒 / 45 度俯拍」等出图措辞 |

> **素材形态纪律**：无论 M0 / M1 / M2，交付首行必须声明形态；本库产出的是**提示词**，不预设本包是否持有图。按 `asset-delivery-modes.md` 核实：M2 仅表示实际素材可访问并登记，不代表授权、锁定或视觉验收。
