## 〇、本库解决什么问题（与既有权威的三层分工）

AI 视频提示词有三种失败：**空泛**（"她很生气"→ 模型给一张平淡脸）、**缺区**（只写眼不写嘴→ 脸发空）、**缺过程**（只写"走过去"→ 人物像滑行）。

既有规则库各自解决一半，本库补的是最后一段翻译：

| 层 | 回答的问题 | 唯一权威 | 本库的角色 |
|---|---|---|---|
| 决策层 | 这一拍**演**什么情绪、为什么这么演 | `acting-direction.md`（五支柱 + 破功句） | **不碰** |
| 面部层 | 脸上**哪块肌肉**动（AU 配方 / 四区拆解 / 强度三档） | `facs-micro-expression.md` | 提供「中文怎么说」的成品短语 |
| 场面层 | 身体**怎么站、怎么走**（站位 / 权力几何 / 节拍） | `blocking-direction.md` | 提供动作槽位式成品短语 |
| **成品层** | **写进提示词的那几个字** | **本库** | **权威** |

> ⛔ **不改判、不改写**：`facs-*` 判定的 AU 配方与强度档，本库只负责**翻译成中文画面语言**；`blocking-direction` 判定的站位，本库只负责**落成动作短语**。两者被推翻时，以各自权威为准。

## 一、三条公式（唯一拼装规则）

### 公式 ①　微表情五件套

```
微表情 + 眼神落点 + 嘴角变化 + 呼吸停顿 + 小动作
```

- **微表情**：眉/眼/瞳孔的肌肉状态——情绪的"底色"；
- **眼神落点**：**看哪里、看多久、往哪滑**——情绪的"方向"，五件套里最容易被忽略、也最能救脸的一槽；
- **嘴角变化**：情绪的"出口"，单边上扬 / 下压 / 抿成一条线 / 抽动各对应不同情绪；
- **呼吸停顿**：情绪的"物理量"（呼吸压住 / 急促而稳 / 断续 / 紊乱）——**模型最容易漏、观众最容易读**；
- **小动作**：手、肩、指、头的微位移——情绪的"替身"，让情绪有落点。

> 库里 `E01~E50` 每条都按这五槽标注（见 §三·表 E）。

### 公式 ②　五官分镜六段式

```
眉 → 眼 → 瞳 → 鼻 → 唇 → 脸颊
```

- **固定顺序、从上往下写**，目的只有一个：**防漏区**。缺区 = 表情发空 = 模型自由发挥崩脸；
- 适合**夸张表情**（漫剧 / 3D CG / 情绪爆点），不適合日常克制表演（日常用公式①）；
- 库里 `F101~F609`（6 卷 × 9 条）全部按此顺序写成。

> ⚠️ 3D CG / 半写实仿真人（`BASE_ANIME`）时**必须**展开六段式——这是 `SKILL.md` §三·法则 13 的形态强制项在本库的落地形态。

### 公式 ③　动作槽位式（十变体）

| 键 | 公式 | 适用 |
|---|---|---|
| `pose_stand` | 角色 + 站姿 + 手部动作 + 视线方向 + 镜头 + 环境光 | 角色出场第一眼 |
| `move` | 角色 + 移动方向 + 步伐节奏 + 衣摆动态 + 跟拍方式 + 环境光 | 走 / 跑 / 停 / 转场 |
| `atmos` | 角色 + 身体倾角 + 手部位置 + 眼神状态 + 镜头距离 + 氛围光 | 氛围感姿态、唯美空镜人物 |
| `press` | 角色 + 身体姿态 + 手部位置 + 头部方向 + 镜头 + 光影压迫感 | 上位者压迫感、强势气场 |
| `emotion` | 眼神 + 眉形 + 嘴角 + 肩部状态 + 手部动作 + 呼吸感 + 镜头距离 | 情绪反应特写、情绪落点 |
| `duo` | 人物A动作 + 人物B反应 + 接触位置 + 距离 + 视线 + 镜头运动 | 双人互动、关系推进 |
| `combat` | 起始姿势 + 攻击方向 + 脚步重心 + 动作轨迹 + 镜头速度 + 冲击效果 | 打戏、追逐、爆发 |
| `career` | 职业 + 制服/服装 + 专业工具 + 标准动作 + 真实工作场景 | 行业职业动作、职场戏 |
| `hook` | 角色 + 身体姿态 + 手部动作 + 头部方向 + 镜头 + 光影氛围 | 前 3 秒钩子、高潮段落 |

> **三段式铁律**：任何动作必须能读出 **起始姿态 → 运动过程 → 收势**。只写"走过去"= 滑行；写成"抬手→触到门把→停住、回头张望"= 有重量的动作。

## 二、强度衰减（景别决定写几槽、写多狠）

| 景别 | 幅度档 | 五件套取槽 | 说明 |
|---|---|---|---|
| 大特写 / 特写 | 痕~显 | **全五槽** | 唯一能承载完整五件套的景别 |
| 中近景 | 痕~显 | 3 槽（微表情 + 眼神 + 嘴角） | 呼吸与小动作只留最明显的一处 |
| 中景 | 痕 | 2 槽（微表情 + 视线） | 表情让位给姿态 |
| 全景 / 远景 | 痕 | 1 槽（视线方向或身体姿态） | 观众只读得出大方向 |
| 群像 | 痕 | 每可见人 1 槽 | 群像表情由 `crowd-behavior-direction.md` 管事务，本库只管姿态 |

- **幅度词不写进投喂正文**：`〔痕/显/强〕` 是 FACS 内部档位标签，**禁入正文**（见 `facs-micro-expression.md` §二·分层铁律）。本库的成品短语自带"微微/缓缓/骤然"等自然措辞，**不要再叠档位标记**；
- **表情不抢台词**：表情 hold 时长不得侵吞台词预算；峰值对齐台词重音，句尾留 0.3~0.8s 余韵（与 `dialogue-speed-check.md` 联动）。

## 五、P3 / P4 接线（两槽）

### 5.1 镜头级两槽

`project_state.json` 的每个 shot 可带两个**成品短语槽**：

```json
{
  "no": 1,
  "spec": "中近景 · 85mm · 侧45度 · 极缓慢推",
  "action": "画面主体：@林风 右手拇指攥紧战术手套魔术贴……",
  "expression": "面部：眼尾泛红、眉心松又拧、视线滑开、嘴角下压",
  "motion": "动作：手伸到半空停住，肩膀微微颤抖"
}
```

- 槽值可直接写裸短语（编译器自动加 `面部：` / `动作：` 标签），也可写带标签的成品句；
- **编译器只接线，不生成**：作者没填 → 一个字都不加（已由 `compile_feed.py` 自测锁死）；
- 槽值与 `action` 已有内容**重复时**不会重复拼入。

### 5.2 自动标注（可选）

```bash
python3 scripts/expression_motion.py --state project_state.json --annotate --out annotated.json
```

- 依据镜行 `action` + `dialogue` + 段类型 + 站位声明 + 音效摘要做检索，**只填空槽**（`--overwrite` 才覆盖）；
- 每条建议同时写 `expression_ref` / `motion_ref`（库条目 id + 命中分值 + 命中词）；
- ⚠️ **分值 < 40 = 弱命中**：约 4 字以内的词面沾边，几乎一定不是编导想要的情绪。CLI 会把弱命中**逐条列出来**，**这些镜必须人工重填**；
- 产出是**建议稿**，最终仍由编导人确认后写回台账；
- ⚠️ 标注结果**不得直接进投喂稿**——必须先由人过一遍（库给的是"画面语言"，但**该不该在这一拍用这个情绪**是编导决策，不是检索结果）。

> **检索是怎么匹配的**（引擎 `expression_motion.py`）：① **分片最长命中**（触发词切成 2~6 字分片，长片优先；分值 = 字数 × 10）② **字符重合兜底**（≥3 字才计、封顶 3 字，分值 = 重合数 × 12；专门兜「瞳孔骤缩」↔「瞳孔骤紧」这类同义不同字）③ **同义词表加权**（分值 = 字数 × 6，**刻意低于同长度分片**——只在分片完全没命中时顶上来，绝不压过更长的实证命中）。

### 5.3 落稿形态

编译后镜行：

```
00:00-00:04 [镜头1] 中近景 · 85mm · 侧45度 · 极缓慢推。画面主体：@林风 ……；面部：眼尾泛红、眉心松又拧、视线滑开、嘴角下压；动作：手伸到半空停住，肩膀微微颤抖。声音：……。台词：……。
```

## 六、四条铁律

1. **只写画面语言，不写结果词**——禁"她很生气/震惊/邪魅/悲伤"；写"眉骨压低、牙关紧咬、下颌咬肌绷紧"（与 `facs-micro-expression.md` §二 一致）；
2. **一镜一主槽**——一个镜头只允许 **1 个情绪主槽 + 最多 1 个副槽**（如「强忍委屈」+「手部小动作」）；堆三四个表情 = 脸糊；
3. **表情峰值对齐台词重音**——句尾留余韵，不得让脸先松、话没说完（与 `dialogue-speed-check.md` 联动）；
4. **动作必有收势**——任何动作短语都要能读出 起始姿态 → 过程 → 收势；缺收势 = 滑行（与 `blocking-direction.md` §节拍闭环 一致）。
