## 一、 基础机位 → 本包合法运镜词对照（术语桥梁，最实用的一节）

原文标题称「8 个基础机位」，**正文只确证 5 个**（`Pan / Tilt / Zoom / Dolly / Truck`，第 6~8 个以省略号带过）；配图为 AI 生成示意图，中文注记字形扭曲（如「Dolly（与轴交角度）」「Truck（跨越运镜）」）**不可采信**。按本包「不编数字、不编内容」纪律，**不补齐、不臆造**。

| # | 英文（内部检索键） | 中文 | 定义（原文口径） | **写进 `spec` 槽要用这个**（`CAM_FAMILIES` 合法词） |
|---|---|---|---|---|
| B1 | `Pan` | 水平摇 | 机位不动，镜头水平左右摇 | 平摇 / 横摇 / 摇镜 |
| B2 | `Tilt` | 俯仰 | 机位不动，镜头上下摇 | 上摇 / 下摇 / 俯仰 |
| B3 | `Zoom` | 变焦 | **镜头不变、焦距变**（画面放大缩小） | 变焦 / 光学变焦 |
| B4 | `Dolly` | 移动机位 | **机位真的在动**（靠近或远离主体） | 推镜 / 拉镜 / 前移 / 后移 |
| B5 | `Truck` | 横向跟随 | 机位横向平移跟随主体 | 横移 / 侧移 / 跟移 |

- **Zoom ≠ Dolly**（原文特别划重点）：想凸出**情绪压迫感**用 Dolly（机位真的压过去）；想模拟**望远镜观察**用 Zoom。
- 本包 `CAM_FAMILIES` 另已有更全的合法运镜词：**固定 / 推 / 拉 / 横移 / 竖移 / 摇 / 俯仰 / 跟 / 升降 / 环绕 / 弧形 / 轨道 / 摇臂 / 光学变焦 / 滑动变焦 / 急推 / 手持 / 漂移 / 甩 / POV / 主观视角 / 荷兰角 / 鱼眼 / 升格 / 降格 / 定格**。写 `spec` 时**直接用中文合法词**，不要写英文——英文术语既过不了 C18g 的族解析，转场类还会撞 C12。
- 检索：`python3 scripts/expression_motion.py --camera Dolly` / `--camera 变焦`。

## 二、 15 个进阶运镜（五类 · 含配图精确参数）

> **读表方式**：`中文正文写法` 进 P4 镜行**正文**；`spec 运镜族` 进镜行**头**（如 `中景 · 50mm · 侧45度 · 跟拍`）；`归属权威` 非空 = 该手法已有权威，本行只是速查指针，**必须回权威文件定判据**。`英文检索键` ⛔ **禁入正文**。

### 第一类 · 高燃动作与追逐（C01~C03）

| ID | 中文名 / 英文键 | 参数 | 中文正文写法 | spec 运镜族 |
|---|---|---|---|---|
| C01 | 疾速追尾镜 `Dynamic Follow` | 保持 **3-5 米**；弯道惯性延迟 | 镜头紧随快速移动目标，保持三到五米距离同步前进，弯道处带一点惯性延迟，沿位移方向动态模糊 | 跟拍 / 跟移 |
| C02 | 飞跃俯冲镜 `Dive & Soar` | 一秒从高空扎到地面 | 视角先急速下降贴近地面再拉起，画面带速度线，一秒内完成从高空到地面的空间落差 | 急推 / 升降 |
| C03 | 打斗穿梭镜 `Combat Weave` | 远景 ↔ 对拳特写 | 镜头在交战双方之间快速穿行，远景与对拳特写交替，招式交锋与受击震动都被带到 | 横移 / 跟移 |

### 第二类 · 战斗高光（C04~C06）

| ID | 中文名 / 英文键 | 参数 | 中文正文写法 | spec 运镜族 |
|---|---|---|---|---|
| C04 | 旋转攻击镜 `Spin Attack` | **360° 环绕 + 每转约 40° 换角度** | 以出招者为轴心高速环绕旋转，转速同步攻击节拍，每转一圈换一个角度 | 环绕 / 弧形 |
| C05 | 躲避晃动镜 `Dodge & Shake` | 剧烈颠簸后稳住约 **0.3 秒** | 闪避瞬间镜头剧烈颠一下，随即稳住约零点三秒，靠颠与稳的对比带出代入感 | 手持 / 漂移 |

## 三、 万能公式（原文）与本包七段式的边界

```
主体描述 → 环境光影 → 运镜提示词 → 速度感描述
例：赛博朋克机甲 ＋ 霓虹灯背景 ＋【疾速追尾镜：镜头紧随，动态模糊】＋ 高速运动
```

- **这是「单条出片提示词」的快速拼装公式**，适合 P4.5 预演 / 单镜试片 / 平台侧独立出片；
- ⛔ **不替代本包七段式**：正式投喂稿仍是 `【画幅风格】【场景资产】【核心人物】【站位声明】【时间轴分镜】【音效】【强制禁止项】`，镜行头用 `[景别] · [视角角度] · [运镜] · [焦段]`（见 `model-adapters.md` §5 / `camera-specs-15rules.md` §二）；
- **公式与本包的对应关系**：`主体描述` → 镜行「画面主体」；`环境光影` → 【场景资产】的时段光影基准（镜行只写增量）；`运镜提示词` → 镜行头 `spec` 槽 + 正文画面描述；`速度感描述` → 动作段的节奏词（须与 C21/C22 打戏激烈度门兼容）。
- 库里另有 **11 套槽位公式**（10 套动作 + 1 套生图六槽），`python3 scripts/expression_motion.py --formula` 可全列。

## 四、 ★ 五条硬冲突裁决（本文件最重要的部分 · 照搬外部写法必踩机检）

> **归纳 ≠ 照抄**。原文面向「通用 AI 视频工具」，本包面向 **Seedance 2.0/2.5 短剧工业管线**，两者的节奏与文字纪律不同。以下五处**以本包铁律为准**。

| # | 原文怎么写 | 本包已有铁律 | **裁决** | 依据 |
|---|---|---|---|---|
| 1 | 「**核心动词翻成英文更准**（Dynamic motion blur / Dolly Zoom）」 | ⛔ 转场术语禁裸写进投喂正文（**C12**）；FACS 分层铁律「中英混排一律禁止」；C18g 机检按**中文** `CAM_FAMILIES` 解析运镜族 | **英文只作内部检索键**，正文一律写中文画面描述；`spec` 槽写中文合法运镜词 | `creative-transition-library.md` §1.3 / `validate_prompt.py` C12_TRANSITION_RE |
| 2 | 「时间凝滞镜：**静止 2 秒**，两秒后缓缓恢复流动」 | **同运镜 ≤2 秒 / 同景别 ≤3 秒**；**升格、慢动作跟镜默认禁用**（2026-09-02 实测破坏节奏）；Time Ramp 仅限命中帧前后 **0.2s**；命中定格 **1~2 帧** | **降级为「命中瞬间定格 1~2 帧」**；保留「碎片悬停、水花定格、细节纤毫毕现」作画面描述；⛔ 禁写 2 秒静止 | `camera-specs-15rules.md` §二 / §四 / §五 |
| 3 | 「记忆闪回镜：**重叠 3 秒**后彻底接管画面」 | 同运镜 ≤2 秒 | **降到 ≤2 秒，或拆成两个镜行** | 同上 |
| 4 | 「多镜组合序列：推→横移→旋转拉远」写成一个「运镜」 | C18 一镜多运镜门；同段运镜不得连排 ≥3 段相同 | **必须拆进时间轴分镜三行**，一行一运镜；⛔ 塞进一行会被机检拦 | `validate_prompt.py` C18g~l |
| 5 | C07~C10 四种转场另起一套写法 | 技巧型转场已有唯一权威（D 锁 ④）；段内六式已有唯一权威 | **本库只做速查指针**，判据回 `creative-transition-library.md` / `camera-transitions-6types.md`；配额单集 ≤3 处 | 元规则一（同概念单一权威）/ `prompt-feeding-checklist.md` 第 33 项 |

### 附二：机检覆盖实测（别把裁决当成「机检会兜底」）

2026-11-15 端到端对照：把照搬外部写法进一份真实投喂稿（`spec` 写 `Dynamic Follow`、正文写 `Bullet Time 全场静止 2 秒，Match Cut 转场`），跑 `validate_prompt.py --model 2.5` ——

| 写法 | 机检结果 |
|---|---|
| `Match Cut` | ✅ **C12 WARN** 拦住 |
| `spec` 全英文、无中文运镜族 | ✅ **C18g WARN** 「镜行未标注运镜」拦住 |
| **`Bullet Time`** | ⚠️ **静默放行**（词表只收转场术语） |
| **「静止 2 秒」** | ⚠️ **静默放行**（无对应子码），稿件仍 `PASSED` |

> **诚实结论**：§四 的冲突 2/3（超时静止）属**语义层纪律，机检没有对应子码**，不能指望 C 码兜底。为此引擎补了轻量守卫 `--guard`，把五条裁决变成可执行的出稿前检查（**不改动 `validate_prompt.py` 的 C 码结构**，避免牵动机检手册与子码登记表）：
>
> ```bash
> python3 scripts/expression_motion.py --guard feed.md     # 0 违规 exit 0；有违规则列裁决并 exit 1
> ```
>
> 对照实测：照抄稿抓到 **4 处**（静止 2 秒 / Dynamic Follow / Bullet Time / Match Cut，含机检漏掉的前两类关键项）；按本库中文写法落成的稿 **0 违规**，且 `validate_prompt` 0 WARN 通过。

### 附：一处原文自相矛盾的裁决

**分身残像镜（C12）的透明度方向**：正文写「透明度**逐级递减**」，配图写「透明度**递增 30%**」。二者矛盾。按视觉物理（离本体越远的残像越淡）与本包 `anime-ultimate-vfx-paradigm.md` 的残影口径，**裁决为「由近及远逐级递减」**，`30%` 保留作每级衰减幅度。⛔ 不与 `sd-xuanhuan-engine` 的「超音速 Z 型移位三件套（折点残影）」叠加——两套残影同轴会糊成一团。

## 六、 使用流程（P3 → P4）

### 6.1 检索

```bash
python3 scripts/expression_motion.py --camera "追车"        # 场景词
python3 scripts/expression_motion.py --camera "子弹时间"    # 中文别名
python3 scripts/expression_motion.py --camera "Dolly"       # 基础机位术语
python3 scripts/expression_motion.py --list cam_move        # 15 条全表
python3 scripts/expression_motion.py --formula              # 11 套公式
python3 scripts/expression_motion.py --guard feed.md       # 出稿前守卫：抓英文术语 / 2 秒静止 / 3 秒重叠 / 残像方向
```

`--camera` 返回四件事：**中文正文写法 / `spec` 合法运镜族 / 精确参数 / 冲突裁决与归属权威**——四样一起给，就是为了防止「只抄了画面描述却漏了 spec 运镜词」被 C18g 拦。
