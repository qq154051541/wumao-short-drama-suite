# 红果短剧交付规格（竖屏 · 可直接上架）

> **定位**：P5 交付层的**平台口径权威**——本包产出要「能直接上架」，格式、时长、字幕、音轨、封面字段一律按本文件。
> ⚠️ **口径声明**：本文件里的平台参数分两类——① **硬约束**（来自平台公开规则或实测反馈，标明来源）；② **经验值**（行业通行做法，标「经验值·待核验」，**以平台最新公告为准**）。⛔ 不把经验值写成硬规则。

---

## 一、交付形态总表（先定这个，再谈内容）

| 项 | 口径 | 类型 |
|---|---|---|
| 画幅 | **9:16 竖屏**（1080×1920），全集统一 | 硬约束 |
| 单集时长 | **60~120 秒**为主流区间；首集可 90~120 秒 | 经验值·待核验 |
| 单镜时长 | Seedance 线 2~6 秒/镜；H3 线 4~15 秒/段 | 硬约束（模型契约） |
| 段长 | Seedance 2.5 ≥12s（推荐 25~30s）；H3 按 4~15s 切 | 硬约束 |
| 集数节奏 | 前 3 秒必须有钩子；每 15~20 秒一个信息点或反转 | 经验值·待核验 |
| 字幕 | 烧录硬字幕，简体中文，随音轨 | 经验值·待核验 |
| 音轨 | 对白 -0 dB / 环境与动作 -6 dB / 配乐 -14 dB（三层相对电平） | 包内既有铁律 |

---

## 二、9:16 安全区（防 UI 遮挡）

- **顶部**：约 12%~15% 高度是状态栏/标题区 → 不放开场字幕的关键信息；
- **底部**：约 20%~25% 高度是操作栏/简介区 → 字幕底边不低于画面高度 78% 处；
- **右侧**：约 12% 宽度是互动按钮列 → 人脸、关键道具不放这一列；
- 首帧与封面必须按上述安全区复核（封面另按平台裁切比例单独出图）。

---

## 三、字幕规范

| 项 | 口径 |
|---|---|
| 字体 | 黑体类无衬线，描边 2~3 px（深色描边 + 浅色字或反之，保证任何背景可读） |
| 字号 | 单行 ≤ 18 个汉字；超过即断行，**单屏最多两行** |
| 断句 | 按语义断，不拆「的/了」类虚词结尾；一条字幕覆盖 1~2 个语音句 |
| 时长 | 最短 0.8 秒、最长 4 秒；进出各留 0.1 秒余量 |
| 位置 | 画面下方安全区内，水平居中；双人对话可用左右分置（同屏不超过两条） |
| 标点 | 句末不加句号；问号/感叹号保留；省略号用「…」 |
| 敏感词 | 按 `platform-safety-compliance-guide.md` + 平台最新词表过一遍，**字幕与音轨同源同改** |

> H3 线：字幕由**原生音轨**反推 SRT（见 `h3-adapter.md` §五），⛔ 不让模型在画面里画字。

---

## 四、开场与收尾（决定完播率的两处）

- **前 3 秒**：必须出现「冲突 / 反常识 / 强情绪」三者之一；⛔ 不用空镜、风景、字幕卡开场。
- **前 10 秒**：交代「谁 / 在哪 / 要干什么 / 有什么阻碍」四要素，缺一项即视为铺垫过长。
- **结尾**：最后 5 秒留**未解问题**（人物动作定格在关键瞬间或一句反问），为下一集留钩；
- **片尾**：不写「未完待续」类字幕卡（平台判低质），用画面钩子代替。

---

## 五、上架字段（交付时必须齐备）

| 字段 | 要求 | 备注 |
|---|---|---|
| 剧名 | ≤ 15 字，含题材词或人设词 | 忌标题党、忌生僻字 |
| 简介 | 60~120 字，讲清「谁 + 遭遇 + 转折」 | 不剧透结局 |
| 标签 | 题材 / 人设 / 情绪 三类各 1~3 个 | 与剧名简介语义一致 |
| 封面 | 9:16，主体居中于安全区，**人物面部清晰、表情有戏** | 单独出图，不复用分镜帧 |
| 集数 | 按剧本分集，单集独立可看 | 每集结尾留钩 |
| 付费/免费点 | **不写进剧本**（本包不承载商业策略） | 需要时由运营侧配置 |

---

## 六、跨集一致性台账（交付前逐项核）

| 维度 | 核什么 | 判据 |
|---|---|---|
| 人物 | 脸型/发型/眉形/瞳色/痣疤等辨识特征 | 与角色四格板一致；同一人跨集**不得换脸** |
| 服装 | 集内是否换装、换装是否有剧情理由 | 无理由换装 = 穿帮 |
| 场景 | 空间结构（门窗位置/家具布局/朝向） | 与场景九宫格一致 |
| 道具 | 单实例锁：同一道具的形制/颜色/磨损 | 跨镜不得变形、不得凭空增减 |
| 光线 | 同一场戏的光源方位与色温 | 反打不得跳变 |
| 声音 | 角色音色（H3 线尤其） | 同一角色音色跨集一致 |

> 任一项不一致 → **先回 P2 资产层改档案**，⛔ 不在 P4 稿里用文字硬描补救。

---

## 七、上架前自检清单（12 项，全过才交）

1. 画幅 9:16 全集一致；2. 单集时长在区间内；3. 前 3 秒有钩子；4. 前 10 秒四要素齐；
5. 字幕断句与音轨对齐；6. 三层电平达标；7. 无平台违禁词（字幕+音轨）；8. 无血腥/低俗/未成年人风险画面；
9. 跨集人物/服装/场景/道具一致；10. 结尾留钩；11. 封面单独出图且面部清晰；12. 剧名/简介/标签齐备。
