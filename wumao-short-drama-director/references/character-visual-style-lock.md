## 〇、 造型参考工作流（先读这条，否则会做错）

> ★ 本锁只回答「这些字段该按什么风格取值、男女主怎么同档不割裂」。**参考图由使用者自备**（本地图片、已获授权素材或自制资产），按九槽位抽取可见的**服装形制 / 材质 / 配色 / 发型 / 配饰 / 妆容浓度 / 遮挡层次**，写进小说里的**虚构角色**。

### 0.1 自备参考图 → 九槽位（四步）

1. **选图**：挑 3~5 张造型方向贴近角色的参考图，放在本地临时目录；
2. **抽槽**：逐图只记造型元素，看不清的写「看不清 / 待补」，⛔ 不凭档位推断填满（参考图常为半身，下装鞋履多不可见）；
3. **落卡**：参考卡记编号 + 九槽位 + 档位，⛔ 不写人物身份、五官辨识特征或吸引力评价；
4. **配对**：按 §四「男女同档配对」补男性角色，再进 `sd-asset-engine` 四格板逐字段落纸。

### 0.2 三条边界

1. **产出是虚构角色**：参考的是**衣服与造型语言**，不复制身份；不把「某某同款」写进提示词；
2. **只写画面元素**：形制 / 材质 / 剪裁 / 配色 / 遮挡关系，⛔ 禁露骨或性化内容；
3. **原图只作本地查看**：⛔ 不打包进交付物、⛔ 不上传给视频模型当参考图（平台限制，见 `SKILL.md` H 节）。写实 / 仿真人画风始终完全支持。

### 0.3 四档造型语言

| 档 | 名称 | 造型关键词 | 适用题材 |
|---|---|---|---|
| **L1** | 现代都市 · 日常通勤 | 日常穿搭、实拍原创、不美颜不滤镜 | 都市情感 / 职场 / 家庭伦理 / 重生现代 |
| **L2** | 现代都市 · 轻修海报 | 轻修时尚海报感、商业人像质感 | 霸总 / 豪门 / 复仇打脸 / 高光集 |
| **L3** | 国风 · 新中式 | 国风、展台、走秀、新中式审美 | 古装 / 宅斗 / 仙侠 |
| **L4** | 国风 · cos / 景区 NPC | cos / 游戏 / 景区 / NPC活动 | 穿越 / 游戏 / 景区实景 / 幻想题材 |

> 四档**共用同一套九槽位骨架**，换档只换槽位取值 + 底模/画风声明，⛔ 不换字段结构。**换风格必须同时换底模与整组锚点，只改几句提示词必崩。**

## 三、 定妆五段式 → 九槽位（把「怎么填」写死）

归纳自本机 `wumao-short-play/references/STYLE_PRESETS.md` 已落地的定妆骨架。**⚠️ 该外部来源用的是「肖像 + 正/侧/背」构图，本包现行标准一律为 4 View 四格板**（面部特写 + 无脸正面 / 90°侧面 / 背面全身，`character-portrait-templates.md:31,75-78`）——本锁只借它的**字段分组**，⛔ 不借它的构图。**五段式是给人看的分组，九槽位是给模板填的字段**，一一对应：

| 五段式 | 对应槽位 | 必写内容 |
|---|---|---|
| ① 脸型轮廓 | `face` | 脸型 + 颧骨线 + 下颌线 + 下巴 + 鼻梁 + 五官比例 + 气质落位 |
| ② 皮肤妆容 | `skin` | 肤色冷暖调 + 皮肤质感（半哑光/极光感）+ **妆容浓度** + 唇色 |
| ③ 眼睛直点 | `eyes` | 眼型组合 + 眼神落点 + 瞳色 + 眼妆色系 + 眼线 + 睫毛 |
| ④ 头发饰品 | `hair` | 发色 + 分缝比例 + 发丝走向与卷度 + 光泽 + 发际线 + 发饰 |
| ⑤ 服装配饰 | `wardrobe` / `prop` / `lower` | 服装形制 + 面料 + 下装/鞋袜 + 手持物 + 造型专属配饰 |
| 构图 / 背景 / 负面 | `expr` / `bg` | **严格按本包 4 View 四格板**（面部特写 + 无脸正面 / 90°侧面 / 背面全身，16:9 横版、不得第 5 格）；纯白柔焦背景；⛔ 禁二次元 / 插画 / 塑料感 / CG 感 / 夸张磨皮 / 花哨背景 |

**填槽纪律**：
- 每个槽位**先写锁内取值（§二 对应档）**，再写角色个体特征；⛔ 禁止只写「按角色设定填」这种占位符交差；
- 五官 10 项（`asset-spatial-ledger.md:9-19`）与服装材质 6 项（`:45-51`）**逐项对槽**，一项都不能漏；
- 8 字段服装模板（`character-portrait-templates.md:185-198`）与本锁 `wardrobe/prop/lower` 对齐，**不新增第二套服装字段**；
- 四格板图面纪律（除图底声纹 + ≤8 词音色标签外零文字）由 `character-portrait-templates.md` 管，本锁不改。

### 3.1 若项目选择 3DCG 路线（本机实测踩坑，⛔ 别照抄真人版词）

本机 `STYLE_PRESETS.md` §五之二记录了**真出图后才暴露**的三个坑，属实测而非推演：

1. **「大眼睛 + 咧嘴笑 + 圆润脸」= Pixar 幼态**：3DCG 里眼睛可比真人略大，⛔ 但绝不能「圆 + 大」；
2. **`peach fuzz`（细密汗毛）在 3DCG 会被画成胡茬**：3DCG 的 `skin` 槽必须把 `a faint peach fuzz` 换成 `clean even shading` 并加 `no facial hair / no stubble`；**真人版必须保留** peach fuzz（写真实皮肤绒毛是对的）；
3. **「3D 国漫」≠「3D 写实」**：`High-end 3D character render` 这类锚点会出成照片级 3D，与真人版看不出区别，须换成真正的国漫锚点。

> 本锁**默认 L1~L4 全部走写实真人质感**（对齐用户要的「真人形象风格」）。切 3DCG 视为换档重开，须同步换底模 / LoRA 与整组锚点，⛔ 不能只改几句提示词。

## 四、 全剧造型统一与层级差（补包内空白）

### 4.1 五项统一（同档内所有具名角色必须一致）

| 项 | 判据 |
|---|---|
| 形制语言 | 同档、同年代的领/襟/袖/腰线体系；⛔ 禁一个角色现代剪裁、另一个古法平面裁剪 |
| 材质语言 | 同一面料家族与光泽度区间；金属件冷暖不混 |
| 妆容浓度 | 全剧同一档浓度（L1 淡妆 / L2 结构妆 / L3 点染 / L4 角色妆），主角可 ±1 级但须写明理由 |
| 年代锚 | 一律服从《世界锚卡》与 `ERA_ANCHOR`（`asset-spatial-ledger.md:284-302`）；⛔ 出现禁用时代元素即 FAIL |
| 发型语言 | 同一打理方式与光泽度；⛔ 禁「一个写实发丝、一个赛璐璐块面」 |

### 4.2 男女主同档但必须差异化（用户明确要求「男性角色同步」）

- **同步** = 同档、同画风基底、同年代锚、同材质家族、共享 ≥1 个辅助/点缀色值；
- **差异** = 骨相棱角、体型与头身比、妆容浓度、服装结构部件、配饰体量**五项分别写**，⛔ 禁「同一张脸换发型」式复制；
- 每对男女主落一行《造型配对表》：`档位 / 女锚点 / 男锚点 / 共享色值 / 五项差异 / 同框校验`，随 P2 HANDOFF 交接；
- 亲缘推导（T1→T2 骨相 40~60%、五官关联、色彩呼应）仍归 `character-lineage-and-sheets.md`，**本锁只在造型层追加**「同档同形制同材质」约束，不改推导算法。

### 4.3 主角 / 反派 / 群像层级差

| 层级 | 造型密度 | 约束 |
|---|---|---|
| T1 男女主 | 九槽位全写、配饰可具名 | 高光集换装须走 `CHAR_STATE` 登记，⛔ 禁静默换装 |
| T2 核心反派 / 亲属 | 九槽位写，配饰减一层 | 与主角同档，用**色值偏移 + 形制微差**区分，⛔ 禁换整套风格 |
| T3 群像 / 路人 | 只写形制 + 主色 + 材质三类 | ⛔ 禁逐人细写五官（既烧预算又易与主角撞脸） |

### 8.3 「美化」三原则（把原文普通形象提档，但不是换脸）

1. **保留辨识特征**：痣、疤、雀斑、虎牙、单眼皮、招风耳——**这些是记忆点，一律保留**，只优化比例、肤质、发型与穿搭。
2. **结构先行，不靠滤镜**：美化落在**骨相比例 / 皮肤质感 / 发型梳理 / 服装剪裁**四件事上；⛔ 不写「磨皮」「美颜」「网红脸」。
3. **同一基准线**：男女主、配角、群像共用一套「肤质/颗粒/锐度」基准，⛔ 不许主角精修、配角糊。

### 8.4 合规红线（写进提示词前必过）

- **Y3/M3 幼态档**：只写「稚气、圆脸、大眼睛、个子小」，⛔ **不写身材曲线、不写暴露、不写任何性暗示**；涉及未成年角色的镜头禁止亲密接触描写。
- **Y6/M6 性感档**：可写到 **L1/L2**（见 §九 分级）——贴身剪裁轮廓、露肩露背剪裁线、腰臀曲线的服装描述、床沿姿态都放开写；⛔ 仍不写「部位尺寸/形状」与「暴露度数值」（技术上是负优化），⛔ L3 三条永不做。
- 所有档位：⛔ 不生成真实人物肖像、⛔ 不模仿在世真人脸；参考图只抽造型语言（见 §〇）。

### 8.5 与九槽位的接线

颜型档决定 **face / hair / wardrobe / expr** 四槽的取值方向，**不新增槽位**；输出时在人物档案首行写 `颜型：Y1 御姐（男配 M1）`，后续跨集沿用同一档，**换档=换人**（需剧情理由）。

## 九、 流量型魅力档（2026-11-16 用户裁定 · 合规版）

> **用户诉求**：参考某些作品的角色气质与舞台系女团形象，「该性感的性感」，要更有流量。
> **本包处理**：⛔ **不复制任何具体角色姓名、外貌设定、作品桥段，也不模仿在世真人 / 明星脸**；只把「类型语言」抽象成可复用的造型维度。
> **分级权限（2026-11-16 用户授权后修订 · 成人角色放开到 L2，L3 永不做）**
>
> **所有具名角色默认成年设定**（未成年角色只走 Y3 非性化路线）。用户明示「我有授权，不需要禁止」→ 本节把原来的"一律不写"改为**四级分级**：L0/L1/L2 都属于**成人角色**可写范围，L3 是三条不可协商的底线。
>
> | 级 | 内容 | 处置 |
> |---|---|---|
> | **L0** | 肩线侧光、锁骨高光、腰线被光勾出、丝质流动反光、湿发贴颈 | ✅ 默认档，放心写 |

> **三条不可协商项（授权也覆盖不到的地方）**

> 1. **未成年人**：这条不是我加的限制，是法律红线（儿童色情内容在任何司法辖区都是刑事问题）。**任何授权都不能覆盖**。"妹妹 / 学园 / 幼态"题材，角色按成年人写、造型走 Y3 非性化路线，这是硬门。
> 2. **性行为过程与性器官细节**：属于色情内容，平台必删、也超出本包"短剧预告级"的表达需要。**要的是张力，不是解剖**——观众被勾住的从来是"没发生的那一刻"。
> 3. **可识别的真实人物面孔**：肖像权**只属于本人，不能由第三方转授**，所以"我有授权"在这里不成立；而且平台对明星脸是直接判侵权下架。**做法**：取"气质类型 + 造型语言"（如"骨相立体、眼尾上扬的冷艳系"），不落任何具体人的五官组合。
