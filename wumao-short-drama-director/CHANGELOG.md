## 一镜一事 + 定版脸 I2VA：修「重复镜头 / 多肢 / 座位乱 / 角色不一致」（2026-11-20 第三轮）

用户第二轮反馈：成片还有重复镜头、人物多肢、车内位置奇怪、角色一致性没锁定、很多不符合常理的镜头。逐条复现后确认**不是参考图没给，而是给了也没用**。

### 1. ★ 核心发现：H3 视频节点的 `ref_image` 是弱参考，锁脸必须走「首帧」

| 实验 | 结果 |
|---|---|
| 把 `MiniMaxH3ReferenceToVideo` 的 ref_image 从「四格板裁的正脸」换成「H3-Image 新生成的定版半身照」，其余全同，重跑 6 个镜头 | 输出 556KB/837KB/673KB/1073KB/1105KB/1169KB —— **前后完全一致**，脸没换 |

→ 改链路：**定版照 →(H3-Image)→ 每镜首帧 →(MiniMaxH3ImageToVideo)→ 5 秒视频**。首帧是同一张脸，5 秒内不会换人。全 21 镜按此重做后，男主全片同一张脸。

### 2. 15 秒一段 = 多肢 / 重复 / 座位乱的共同源头

- 一个 7.5 秒镜头写「走过来→开门→上车→关门」四步 → H3 循环演三遍（上车→下车→再上车，字幕跟着重念）。

## 导演台视频识别 + H3「人脸一直变/人一会儿车里一会儿车外」根因治理（2026-11-20）

用户四条反馈：① 导演台里视频没数据、生成完也不显示 ② 人物脸一直在变 ③ 分镜衔接差 ④ 站位乱（一会儿车里一会儿车外、开车门很奇怪）。逐条定位到**工程 bug + 参考图错喂 + 段缝策略错**三类问题。

### 1. 导演台「已出片却显示未生成」（`director_server.py`）

- 病根：`clip_for_seg()` 只认 `progress.done` 登记与 `clips/raw/local-runner/S01-040mp*.mp4` 老命名；实际出片落在 `06_delivery/clips_hd/E01_S01.mp4` → 六段全部 `has_clip=false`，分集点播 `0/6`。
- 修法：新增 `CLIP_DIRS = 06_delivery/clips_hd → clips → clips/final → clips/raw → clips`，按**文件名 token**（`S01`，不分大小写、任意位置）匹配，同目录取最新；`progress.done` 仍最高优先。
- 同一病在 `find_film()`：`ep` 是内部 ID `E01`，交付件是中文名 `神豪-第01集-成片-HD.mp4` → 旧 pattern `*E01*` 永远不中。现在同时尝试 `第01集 / 01集 / E01`，并**HD/高清优先**再按时间。
- 实测：`has_clip` 0→6，`film=06_delivery/神豪-第01集-成片-HD.mp4`（90.53s）。

### 2. 「节奏预演」tab 补本段成片播放器（`director_ui.html`）

该 tab 字面写着"纯浏览器文字预演，不是视频或声音"，用户点进去看到空白自然以为"没数据"。`renderPreview(shots, media)` 新增顶部卡：有片直接播（`imgUrl()` 带时间戳绕缓存），没片明确写"该段还没有成片"。

### 3. ★ 根因：设定板不能当 H3 的 ref_image（新增 `scripts/build_h3_refs.py`）

抓帧比对后发现三块设定板全是"多格拼图"：角色板 = 1 张大脸 + **3 套无脸人台/无头衣服** + 飘浮发型；场景板 = 3×3 九宫格且每格压着 AI 生成的乱码铭牌；道具板 = 2×2。H3 抓到哪格算哪格 → 脸每段都不同、空间随机、画面出现半截无头身体。

新增派生脚本：
- 人物：自动找「大脸 ↔ 换装区」背景竖缝（限制在 0.20–0.46 宽度，防止把整排无脸人台裁进来）→ 正脸居中贴 9:16 画布；
- 场景/道具：按 `cell:[row,col]` 取单格、`trim=46` 裁掉标题条、`GaussianBlur(1.6)` 糊掉乱码字与假按钮；
- 产物落 `02_assets/h3_refs/`，spec 落 `02_assets/h3_refs.spec.json`（跟着项目走，可人工改格位）。

`refs.json` 因此变成双轨：`file` 给看板看四格板，`h3_file` 给 H3 出片，互不污染。

### 4. 段缝 AddGuide 不再全段硬接（这是"人一会儿车里一会儿车外"的真凶）

六段全接 = 强迫每段首帧复制上一段构图。而 S01→S02 跨夜、S02→S03 跨地点、S03→S04 跨时间、S04→S05 换机位——全都不该接。改为 `GUIDE_FROM_PREV = {6}`（只有 S05→S06 是同机位同光位连续动作）。判定口诀写进 `h3-adapter.md` 坑 6。

### 5. 每段出场的人都要有自己的 refs 条目（坑 7）

S03/S04 原来只给知夏，李洛在这两段里又露脸又说话 → 脸全靠模型现编。现在 S03/S04 都是「知夏+李洛+校门+车厢驾驶位(+后排/包)」五张，`<Picture N>` 与 json 槽位用脚本校验（`缺定义` 才允许出片）。

### 6. 动作单步化 + 两条新护栏（`h3-adapter.md`）

S03 连跑三次才定位：一个 7.5s 镜头写「走过来→开门→坐进去→关门」四步，H3 会**循环**（上车→下车→再上车，字幕跟着重念）。改为"起点推到动作中段"（already seated / door swinging shut）+ 三句否定护栏（does not walk around / does not get out again / does not repeat the entry）。同时补：空座位要显式写 `nobody sits in it`（实测副驾冒出第三人）；一镜只做一件事，画外音写 `off-screen`（否则镜序被打乱）。

### 7. 重出片后必须删旧抽帧

`ensure_shot_frames()` 只在文件不存在时抽帧 → `05_qc/machine/storyboard/{seg}_shot*.png` 不删就永远显示旧片画面。已写入避错清单。

### 8. 720×1280 本机跑不了 15 秒（实测封档）

请求 `length=362`，`ContextWindows` 自动降级为 `context_length=37 / 107 帧`（≈4.5s），6 步 10 分钟只出 4.5 秒。**480×864 是本机 15s 上限**；分辨率也不是人脸漂移的解药。

### 9. 新增 `scripts/sync_prompt_md.py`

只维护 `prompt.txt`，`prompt.md`（分镜卡 + 投喂原文）由脚本按 `[Shot N]` 切分生成，台词列从 `<d>[Chinese]…</d>` 提取，幂等可反复跑。治"改了一处忘另一处、导演台分镜卡与实拍对不上"。
